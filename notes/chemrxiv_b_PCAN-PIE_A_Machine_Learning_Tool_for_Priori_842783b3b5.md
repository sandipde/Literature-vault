## Summary
Prodrug design enhances critical drug properties by creating drug derivatives with improved properties while harnessing metabolic activation to regenerate the active pharmaceutical ingredient (API) in vivo . However, reliably predicting whether a prodrug converts to the intended API remains challenging, causing project failures and limiting systematic exploration of prodrug design spaces. Here, we developed PCAN-PIE (Prodrug CAndidate Navigator using a Paired-Input Ensemble), a machine learning tool to de-risk prodrug design by distinguishing prodrug candidates likely to release their intended API from those unlikely to activate. PCAN-PIE demonstrates strong performance across different approved prodrug activation chemistries, can identify competing metabolic pathways that may compromise activation, and correctly triages chemically plausible but unreported transformation products. Attribution analysis suggests that PCAN-PIE bases its predictions on chemically meaningful reactive substructures, providing medicinal chemists with an interpretable rationale for candidate prioritization. In a prospective four-candidate prodrug design campaign, PCAN-PIE successfully prioritized the two candidates that ultimately demonstrated measurable API formation and cellular activity, while deprioritizing two candidates that showed negligible conversion and activity. Taken together, this work establishes PCAN-PIE as a focused computational tool for prioritizing prodrug candidates and provides a framework for integrating structure-based prediction into rational prodrug design to support the development of safer and more effective medicines.
