## Summary
Growing deployment of lithium-ion batteries has intensified the need for advanced battery pack simulation tools to address the key engineering challenge of accurately predicting the electrical and thermal behaviour of battery packs. This work presents a scalable, physics-based simulation framework for arbitrary (Ms, Np) lithium-ion battery pack configurations. The framework is demonstrated and experimentally validated using a 4s4p pack with bottom cooling. Experiments were conducted on the pack, with temperatures measured throughout the assembly using 80 thermal sensors distributed uniformly across the pack. The resulting spatially and temporally resolved temperature measurements, together with measured pack voltage, are compared directly with model predictions obtained using both the standard expression for irreversible heat generation and the energetically consistent expression derived in [27], which includes heat of mixing within the electrode particles. The heat-transfer model is parametrised using a charge–discharge protocol that yields the same heat-transfer coefficients for both heating formulations. The standard expression gives only moderate agreement with the measured temperatures, whereas simulations using the energetically consistent expression show very good agreement with both the temperature evolution across the pack and its electrical response. The approach represents each cell as a set of spatially resolved finite sections, each governed by the full Doyle–Fuller–Newman (DFN) equations, with all sections coupled thermally and electrically. For the 4s4p case, this results in a network of 80 simultaneously solved DFN models. This formulation enables detailed prediction of intra-pack thermal and electrochemical behaviour. The simulation platform is implemented as a flexible API. The resulting tool can support the design of more reliable and longer-lasting lithium-ion battery systems across a range of large-scale applications.
