# EGQCA Code: automated high-throughput thermodynamic modeling of solid solutions

- **Published:** 2026-11-25

## Summary
Modeling disordered systems from first principles across the full composition range is a long-standing computational challenge. We present a code package implementing the extended generalized quasichemical approximation (EGQCA), which describes solid solutions through the statistics of a finite set of clusters and enables their thermodynamic modeling at arbitrary compositions and temperatures. The package automates the complete workflow and interfaces with both DFT codes and universal machine-learned interatomic potentials (uMLIPs). We show that replacing DFT with uMLIPs reduces the cost of the cluster calculations by up to five orders of magnitude while preserving the thermodynamic predictions. To make computationally demanding properties tractable, we additionally introduce a cluster-selection algorithm that identifies the most relevant configurations. Together, these developments establish EGQCA as a fast and accurate framework for the thermodynamic modeling of solid solutions and a practical route toward high-throughput screening of disordered materials.
